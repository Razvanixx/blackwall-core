# Governance

Blackwall Core is currently maintained by the repository owner. Maintainer identities and permissions must match the actual GitHub organization; the project does not use fictional team members or approvals.

The maintainer is responsible for releases, security advisories, roadmap decisions, and enforcement-boundary claims. Contributors may earn commit or review access through sustained, constructive work after the public project establishes a review process.

Architecture and compatibility decisions are recorded in `docs/adr/`. Security claims require testable evidence. Commercial product priorities do not silently change public protocol guarantees.
