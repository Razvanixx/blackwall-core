# Support

Blackwall Core is experimental community software without a service-level agreement.

- Use GitHub Issues for reproducible bugs and documentation problems.
- Use GitHub Discussions for design questions only if Discussions are enabled.
- Use the private process in `SECURITY.md` for vulnerabilities.
- Commercial product support is separate from this repository and will be documented only when available.

Do not use this project as the sole protection for a production endpoint or an untrusted AI workload.
