# Code of Conduct

## Our standard

Participation must remain respectful, technically honest, and focused on improving the project. Welcome questions asked in good faith. Critique code and claims with evidence. Respect privacy and coordinate security disclosures privately.

Harassment, discrimination, threats, doxxing, deliberate disruption, fabricated identities, and knowingly false security claims are not acceptable.

## Enforcement

The repository maintainer may edit or remove contributions and restrict participation when behavior violates this standard. Serious security or safety concerns should be reported through the private process in `SECURITY.md`.

This policy applies to project repositories, issue trackers, reviews, discussions, and official project spaces.
